# First two screens: illustrated comic adventure

Scope: welcome / adventure trail (#map) and first learning activity (#mystery), confirmed by the user on 15 October 2026. The thermometer screenshot is an anti-reference for the repeated generic visual design. No redesign of the subsequent lessons is included in this preview.

The user asked for a fun, playful UI with cartoons and drawings, built for them to judge. This is a code-led preview. The concept is a children's printed comic adventure: exuberant full-bleed garden artwork, confident ink, oversized Lilita One lettering, Caveat marginal handwriting, warm yellow, coral, leafy green and blue. Live HTML owns every heading, speech bubble, action and navigation item. The illustrations are asset plates, not screenshots of UI.

First viewport: an edge-to-edge illustrated comic cover. Sprout and Beep fill the garden to the right, while the title and invitation occupy the clear sky. The lower-right page turn opens the first mystery. Seven open trail markers below retain access to all learning stations and completion state.

Second screen: a close-up comic panel paired with the learner's first prediction. Sprout stays visibly rooted. Selecting any of the three ideas gives supportive feedback, marks the discovery, and reveals the existing leaf-story link. No scored quiz is added.

Typography: local Lilita One for display, existing Nunito for readable body and controls, local Caveat for short conversational notes. Source font licenses ship with the assets. Art was generated with built-in imagegen; exact prompts are in first-screens-art.json. WebP conversion preserves the original source PNGs.

Responsive: header reflows at 760px; hero copy sits above a character crop; the trail becomes a connected vertical list; the mystery stacks scene then choices. Low-data, larger text, reduced-motion and read-aloud controls remain supported. Colors and header overrides are scoped to the two routes.

Risk: the following screens deliberately retain the earlier art direction while the user evaluates this preview. Later rollout would need consistent character art across that larger journey.
