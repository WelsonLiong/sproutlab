# Adult usability test record

Status: NOT YET CONDUCTED. Technical and AI-agent checks do not count as the two adults required by the TPB.

Use two consenting adults. Identify them as Tester A and Tester B in the report; keep unnecessary personal details out of the product. Ideally one checks primary science/pedagogy and one checks ordinary user navigation. Record device, browser, date and actual duration.

Tasks for each tester:
1. Start at the map and explain the learning goal.
2. Make a prediction and use both manual and playback story controls.
3. Run an all-needs-present trial; remove only sunlight and run a comparison.
4. Solve both creek levels; try a disconnected path and use the hint.
5. Read two evidence sources, repair the AI claim and redact private data.
6. Make an assessment error, read feedback, complete and retry.
7. Save a reflection, reload, inspect the journal and download a copy.
8. Use keyboard only, mobile width, larger text, reduced motion and the offline trail.

For each task record: completed independently / completed with help / not completed; time; exact difficulty; tester comment; severity; proposed improvement. Record observed evidence rather than guessed opinions.
